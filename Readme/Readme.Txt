🛠️ Technologies and Libraries Required

Technologies Used:

Python: The core programming language for backend development.

Streamlit: A framework to build interactive web applications with Python.

Pickle: Used to serialize and save movie data and the similarity matrix.

scikit-learn: A machine learning library for vectorization (text to numerical data) and calculating similarity between movies.

NLTK (Natural Language Toolkit): For natural language processing, specifically for stemming and text cleaning.

Pandas: Used for handling and processing datasets (movies and credits).

NumPy: For numerical operations, especially matrix computations related to similarity.}
